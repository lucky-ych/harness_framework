# Harness 저장소 진입점

이 저장소에서는 [배포용 Harness 스킬](../../../skills/harness/SKILL.md)을 읽고 그 지침을 따른다. 실행기·템플릿·참조 문서의 기준 경로는 이 진입점이 아닌 `skills/harness/`다. 작업 대상 프로젝트의 경로는 스킬 설치 위치와 별도로 지정한다.

다른 프로젝트에 설치할 때는 `skills/harness/` 폴더 전체를 복사한다.
